# Expected Product Features

## User Management

- Create users.
- Send email notifications.
- Select organizational unit.
- Select career.
- Modify user data.
- Assign permissions in event programs and activities.

## Event Programs And Activities

- Create event programs with name, dates, custom label, and banner.
- Every organizational unit has a permanent default event program.
- Add collaborators and permissions to event programs.
- Event program collaborators and permissions are inherited by their activities by default.
- Create activities inside an event program.
- Activities include name, type, speakers, classroom, date, time, required equipment, and banner.
- Show users who already have inherited permissions when a local activity collaboration is added.
- Archive event programs instead of deleting them.
- Cancel or delete activities according to the applicable retention rule.
- Ask whether registered attendees should be notified before modifying, cancelling, or deleting an activity.
- Show an activity catalog view with available and past activities.
- Allow filtering by organizational unit and unit type.
- Prioritize activities related to the selected organizational unit.

## Attendance

- Register attendance for a specific activity.
- Support QR code attendance.
- Support manual attendance codes.

## Certificates

- Generate attendance certificates automatically.
- Generate certificates from the attendance list.

## Classroom Inventory

- Manage available classrooms.
- Classroom types include laboratory and classroom.
- Store available hours.
- Store available days.
- Store maximum capacity.
- Store amenities such as projector, desks, tables, smart board, and whiteboard.

## Speaker Registration

- Provide a speaker registration form.
- Capture first name and last name.
- Capture email.
- Capture CV.
- Capture approximate duration.
- Capture talk type such as workshop, seminar, or similar.
- Capture proposal title and content.
- Capture submission date.
- Optionally forward the form to a specific email.
- Specify the event program the speaker is applying to.

## Reports And Statistics

- Show attendance numbers.
- Export reports to Excel.
- Export reports to PDF.
