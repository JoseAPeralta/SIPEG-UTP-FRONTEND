# Fase 7.4 - Marcar alertas como leidas - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir marcar una alerta o todas las alertas propias como leidas desde la bandeja personal, con actualizacion optimista, rollback exacto ante fallo y sincronizacion inmediata del indicador global de no leidas.

**Architecture:** El puerto `AlertsAdapter` suma `markAlertRead` y `markAllAlertsRead`, que los adapters API y mock validan antes de exponer. Un modelo puro `alertReadUpdates` aplica la intencion de lectura sobre cada pagina cacheada segun sus filtros. El hook `useAlertReadMutations` orquesta `cancelQueries`, snapshot, escritura optimista, rollback y revalidacion por identidad, con una unica accion pendiente. `useAlertsInbox` compone las acciones y `AlertsInboxView` las presenta con anuncios discretos y foco estable.

**Tech Stack:** React 19, TypeScript 6, Chakra UI 3, TanStack Query 5, React Router 8, Vitest 5, Testing Library, Storybook 10.

**Contrato verificado contra el backend vivo el 2026-10-05:**

- `PATCH /api/v1/alerts/{id}/read` con `bearerAuth`, sin body. Devuelve el envelope habitual con `data: Alert`. Errores `400`, `401` y `404`; ausencia y propiedad ajena comparten el `404`. Idempotente sobre una alerta ya leida.
- `POST /api/v1/alerts/read-all` con `bearerAuth`, sin body. Devuelve `data: { updatedCount }`; repetir la llamada informa cero y nunca toca a otro destinatario.

**Decisiones registradas:**

- **Una sola accion pendiente por identidad:** un guard de mutacion impide que dos acciones simultaneas produzcan snapshots que se pisen al hacer rollback. Los controles se deshabilitan mientras hay una accion en vuelo.
- **Rollback e invalidacion con guardia de identidad:** los callbacks tardios no restauran ni invalidan la cache de una cuenta que ya no es la actual, para no resucitar datos de otra sesion.
- **`updatedCount` sale del servidor:** el mensaje de exito de "marcar todas" usa la cifra real devuelta por el backend, nunca `items.length`, que subcontaria una bandeja paginada.
- **El filtro no cambia el alcance:** "marcar todas" afecta a toda la cuenta, no solo a la pagina o al filtro visibles; la UI lo advierte con el nombre de la accion.
- **Foco estable:** al retirar la tarjeta marcada, el foco pasa a la lista de alertas o al estado vacio, no al `body`.
- **Sin persistencia:** las alertas siguen fuera de `PERSISTED_QUERY_KEY_ROOTS`; la politica general de refresco pertenece a 7.5 y la limpieza de identidad a 7.6.

function readData(payload: unknown, context: string): Record<string, unknown> {
  const envelope = readObject(payload, context);
  if (envelope["success"] !== true) fail(`${context}.success`, "debe ser true");
  readString(envelope["message"], `${context}.message`);
  return readObject(envelope["data"], `${context}.data`);
}

export function mapAlertResponse(payload: unknown, context = "alertResponse"): Alert {
  return mapAlert(payload === undefined ? payload : readData(payload, context), `${context}.data`);
}

export function mapMarkAllAlertsReadResult(
  payload: unknown,
  context = "markAllAlertsRead",
): MarkAllAlertsReadResult {
  const data = readData(payload, context);
  const updatedCount = readInteger(data["updatedCount"], `${context}.data.updatedCount`);

  if (updatedCount < 0) fail(`${context}.data.updatedCount`, "no puede ser negativo");

  return { updatedCount };
}

- [ ] **Step 3: Implementar `alertReadUpdates.ts`**

```ts
import type { AlertFilters, AlertsPage } from "./alert";

export type AlertReadIntent =
  { alertId: string; kind: "one"; wasUnread: boolean } | { kind: "all" };

export function applyAlertRead(
  page: AlertsPage,
  filters: AlertFilters,
  intent: AlertReadIntent,
): AlertsPage {
  if (intent.kind === "all") {
    if (filters.isRead === true) return page;
    if (filters.isRead === false) {
      if (page.items.length === 0 && page.total === 0) return page;
      return { ...page, items: [], total: 0, totalPages: 1 };
    }
    if (page.items.every((alert) => alert.isRead)) return page;
    return { ...page, items: page.items.map((alert) => ({ ...alert, isRead: true })) };
  }

  if (filters.isRead === true) return page;

  if (filters.isRead === false) {
    const present = page.items.some((alert) => alert.id === intent.alertId);
    const total = Math.max(0, page.total - (intent.wasUnread ? 1 : 0));
    if (!present && total === page.total) return page;
    return {
      ...page,
      items: page.items.filter((alert) => alert.id !== intent.alertId),
      total,
      totalPages: Math.max(1, Math.ceil(total / page.limit)),
    };
  }

  let changed = false;
  const items = page.items.map((alert) => {
    if (alert.id !== intent.alertId || alert.isRead) return alert;
    changed = true;
    return { ...alert, isRead: true };
  });

  return changed ? { ...page, items } : page;
}
```
