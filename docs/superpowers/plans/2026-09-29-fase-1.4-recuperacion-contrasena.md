# Fase 1.4 Recuperacion De Contrasena Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anadir solicitud y restablecimiento de contrasena con respuestas anti-enumeracion de cuentas, sin exponer tokens y usando solo el contrato OpenAPI confirmado.

**Architecture:** Se amplia `AuthAdapter` con dos operaciones publicas sin autenticacion (`requestPasswordReset`, `resetPassword`). Los adapters validan el sobre `EmptyData` antes de exponerlo, los hooks envuelven `useMutation` sin query keys ni persistencia, y las paginas son las unicas que leen el token de la URL. La UI recibe props y callbacks; las paginas componen formularios conectando los hooks.

**Tech Stack:** React 19, TypeScript 6, Vite 8, Chakra UI 3, React Router 8, TanStack Query 5, Vitest 5, Testing Library, Storybook 10.

## Contrato Verificado

Consultado con `pnpm run api:contract -- get POST /api/v1/auth/forgot-password` y
`pnpm run api:contract -- get POST /api/v1/auth/reset-password` contra el backend vivo.

`POST /api/v1/auth/forgot-password`

- Publico, sin `security`.
- Body: `{ email: string (format email, pattern estricto) }`, `required: ["email"]`.
- `200`: `{ success: true, message: string, data: EmptyData }`, aunque la cuenta no exista.
- `400` y `429`: `ApiErrorResponse`.

`POST /api/v1/auth/reset-password`

- Publico, sin `security`.
- Body: `{ token: string (minLength 1), newPassword: string (minLength 12, maxLength 128) }`.
- `200`: `{ success: true, message: string, data: EmptyData }`.
- `400` y `429`: `ApiErrorResponse`.

### Decisiones

- **Ruta de solicitud:** `/forgot-password` (coherente con `/login` y `/verify-email`).
- **Ruta de restablecimiento:** `/reset-password?token=...`; el backend genera ese enlace
  (`AUTH_PASSWORD_RESET_URL` por defecto `http://localhost:5173/reset-password`).
- **Token:** se captura una vez al montar y se borra de la barra inmediatamente con
  `history.replaceState`. Nunca aparece en DOM, logs, query keys, navegacion ni almacenamiento.
- **Anti-enumeracion:** la confirmacion de solicitud es texto fijo del frontend; el texto del backend
  no se muestra nunca. El mock no modela existencia de cuenta.
- **Largo de contrasena:** el frontend exige **entre 12 y 20 caracteres** en el flujo de
  recuperacion, decision de producto del usuario mas estricta que el `maxLength: 128` del contrato.
  Divergencia a revisar: `RegisterForm` sigue aceptando hasta 128 caracteres.

> **Nota de cierre (2026-09-29, Fase 1.5).** El backend ajusto despues `register`, `reset-password`
> y `change-password` a `minLength: 12` y `maxLength: 20`. La divergencia quedo cerrada: el
> registro paso a exigir el mismo rango y los tres formularios comparten la politica de 12 a 20. El
> contrato transcrito arriba se conserva tal como se observo en esta fase.

- **429:** se muestra un mensaje localizado de espera, distinto del error generico.
- **Sin query keys:** son mutaciones efemerales; no se invalidan ni persisten consultas.

```ts
export const PASSWORD_RESET_MIN_LENGTH = 12;
export const PASSWORD_RESET_MAX_LENGTH = 20;

const EMAIL_PATTERN =
  /^(?:[A-Za-z0-9_'+-]+\.)*[A-Za-z0-9_'+-]*[A-Za-z0-9_+-]@(?:[A-Za-z0-9][A-Za-z0-9-]*\.)+[A-Za-z]{2,}$/;

export type PasswordResetRequestErrors = Partial<Record<"email", string>>;
export type NewPasswordErrors = Partial<Record<"confirmPassword" | "newPassword", string>>;

export function isValidEmail(value: string) {
  return EMAIL_PATTERN.test(value.trim());
}

export function validatePasswordResetRequest({ email }: { email: string }) {
  return isValidEmail(email)
    ? { email: email.trim() }
    : { email: "Ingrese un correo electrónico válido." };
}

export function validateNewPassword({
  confirmPassword,
  newPassword,
}: {
  confirmPassword: string;
  newPassword: string;
}): NewPasswordErrors {
  if (newPassword.length < PASSWORD_RESET_MIN_LENGTH) {
    return {
      newPassword: `La contraseña debe tener al menos ${PASSWORD_RESET_MIN_LENGTH} caracteres.`,
    };
  }

  if (newPassword.length > PASSWORD_RESET_MAX_LENGTH) {
    return {
      newPassword: `La contraseña no puede exceder ${PASSWORD_RESET_MAX_LENGTH} caracteres.`,
    };
  }

  if (confirmPassword !== newPassword) {
    return { confirmPassword: "Las contraseñas no coinciden." };
  }

  return {};
}
```
