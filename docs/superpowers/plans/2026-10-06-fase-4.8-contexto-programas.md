# Fase 4.8 — Contexto de trabajo con programas legibles

> **Ejecución:** `executing-plans` con subagentes por bloque, TDD y revisión entre integraciones.
> Depende de Fase 4.7 integrada y verificada.

**Objetivo:** seleccionar cualquier programa legible como contexto administrativo, resolver sus
actividades y limpiar una selección cuando deje de estar disponible.

**Arquitectura:** Zustand conserva solo `{ kind, id }`; TanStack Query conserva lecturas privadas por
identidad. El contexto usa una modalidad completa del catálogo compuesto; las operaciones de
colaboradores conservan el descubrimiento autorizado de Fase 3.

**Stack:** React 19, TypeScript, TanStack Query, Zustand, Chakra UI v3, Vitest, Testing Library,
Storybook.

## Reglas de comportamiento

| Situación                              | Comportamiento                                             |
| -------------------------------------- | ---------------------------------------------------------- |
| Programa legible en cualquier estado   | Puede seleccionarse                                        |
| Archivado que sigue siendo legible     | Conserva su selección                                      |
| Programa sin actividades               | Contexto válido con colección vacía                        |
| Carga o refresco pendiente             | No borrar la selección                                     |
| Fallo de red o validación              | Conservar selección; mostrar fallo y recuperación          |
| Lectura completa confirma ausencia     | Limpiar selección y anunciarlo                             |
| Cambio de identidad o cierre de sesión | Limpiar contexto de la sesión anterior                     |
| Pérdida de acceso operativo            | Retirar selección y recuperar navegación en `/operaciones` |
